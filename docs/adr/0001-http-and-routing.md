# ADR 0001：使用标准库 HTTP 与显式路由

- 状态：Accepted
- 日期：2026-11-10

## 背景

Gemvault 的 HTTP 接口数量有限，但对流式正文、Range、条件请求、Digest 和错误语义要求较高。Web 框架的基准 QPS 与真实 Registry 工作负载并不等价。

## 决定

采用 Crystal 标准库 `HTTP::Server`，由项目显式路由到公共源、私有源和健康检查。暂不使用 Kemal 或完整 ORM。

## 后果

优点是关键 HTTP 行为可控、依赖少、容易注入测试替身。代价是需要自行维护路由、中间件顺序和错误处理。

当路由复杂度真正增加时，可以重新评估框架；不能为了沿用初始决定而复制大量成熟框架能力。
