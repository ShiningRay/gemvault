# ADR 0003：首版采用单实例 SQLite 与本地对象存储

- 状态：Accepted
- 日期：2026-11-10

## 背景

首个版本需要简单部署和明确的崩溃一致性，而多实例共享文件和外部数据库会显著扩大测试范围。

## 决定

SQLite 保存私有元数据、权限与索引状态；本地磁盘保存 Gem 和索引文件。启用 WAL、foreign keys 和 busy timeout，使用临时文件＋原子 rename。

仅允许一个写实例访问一套数据目录，不支持 NFS 等多机共享方式。

## 后果

优点是部署简单、备份边界清楚。限制是垂直扩展为主，无法承诺高可用。存储访问必须经接口隔离，未来才能评估 PostgreSQL 与对象存储。
