# ADR 0002：公共索引保真代理，私有索引独立生成

- 状态：Accepted
- 日期：2026-11-10

## 背景

Bundler Compact Index 支持 Range 增量更新、ETag 和完整表示的 `Repr-Digest`。简单地缓存分片、替换索引或计算分片摘要都可能导致客户端校验失败。

## 决定

公共 `/versions` 和 `/info/:name` 首先实现字节保真代理，保留必要的条件请求与缓存 Header。私有源由已提交的元数据生成完整索引快照，并原子替换。

公共与私有源不合并依赖解析结果。

## 后果

首版减少协议偏差和依赖混淆风险，但公共索引离线和高效增量缓存需要额外设计。私有 `/versions` 在数据量增大前采用整体快照，Range 增量延后实现。
